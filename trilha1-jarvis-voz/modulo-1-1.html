CONSTRUA O SEU PRÓPRIO JARVIS

6 PROMPTS · UMA NOITE · UM SEGUNDO CÉREBRO DE IA FALANTE

Este é o método exato que usei para construir o JARVIS com o assistente de código — reduzido a uma sequência de prompts que qualquer pessoa pode executar. Cole-os em ordem, um de cada vez, e o assistente constrói tudo para você. Não é necessário programar. Você apenas supervisiona.

O que você terá ao final: uma galáxia de conhecimento 3D das suas próprias notas · um assistente de voz que responde em voz alta com base nelas · a câmera que mergulha até a fonte · e uma personalidade com uma ironia afiada que te chama de "senhor."

Antes de começar (5 minutos)

O assistente de código instalado e logado → claude.com/claude-code

Google Chrome — o microfone e a voz precisam dele (Safari não serve)

Uma pasta de notas em markdown (vault do Obsidian, Notion exportado, qualquer coisa com arquivos .md). Não tem? O Prompt 1 cobre isso.

Uma chave de API para o cérebro do assistente → console.anthropic.com ($5 de crédito é suficiente; as respostas custam frações de centavo)

⚠️ A única regra: nunca cole sua chave de API em nenhuma janela de chat. Você mesmo a digitará em um arquivo de configuração no Prompt 2. Qualquer coisa colada em um chat deve ser tratada como exposta. Confie em mim nisso.

Abra um terminal, crie uma pasta vazia e inicie o assistente de código dentro dela:

mkdir my-jarvis && cd my-jarvis && claude

Execute os prompts em ordem. Deixe cada um terminar e teste antes de passar para o próximo.
