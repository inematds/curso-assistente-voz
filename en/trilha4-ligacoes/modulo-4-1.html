JARVIS Makes Calls · Module 1/4

How the agent works

The Jarvis Phone Pack

Jarvis Phone Pack The exact calling-agent scripts behind my AI assistant’s real calls — reservations, inquiries, and the code-controlled receptionist — plus the one-paste prompt that turns a voice note into a client-ready invoice on your phone. Every rule here exists because a real call went wrong without it.

How to use this pack

What you need: the coding assistant (claude.com/claude-code), a Retell AI account with a phone number (retellai.com — a few dollars a month; the Verified Phone Number add-on removes the "Likely Spam" caller ID and is worth it from day one), a Telegram bot via @BotFather (two minutes, free), and Google Chrome — the invoice engine prints PDFs through headless Chrome. Optional: an ElevenLabs voice clone so the agents speak in your voice.

The build’s structure: a single brain (the coding assistant + your notes) behind every interface — your desk microphone, Telegram, and a real phone line. Outbound calls use the three scripts in this pack; receipts come back to your phone: the call result, the invoice PDF, the calendar entry.

1 Paste Scripts 1–3 into the Retell agents without edits the first time. Each follows Retell’s official prompt structure (Identity / Guardrails / Task steps / Edge cases / Hard rules). Add the end_call and press_digit tools to each agent, then replace [YOUR NAME] and fill in your dialer’s {{variables}} for each call.

2 Set begin_message to an EMPTY STRING in outbound agents. An empty string means the agent waits for their "hello." Null means it talks over their answer. This one character is the difference between being charming and being incoherent.

3 Set a default for every {{variable}}. An unfilled variable is read aloud as "curly brace party underscore..." on a live call. Defaults like "the reservation" and "the requested time" make that impossible.

4 Your first call is to yourself. Point the reservations agent at your own cell phone and play the restaurant. You’ll hear all the rules working — and never skip this step twice.

5 The one rule: never paste an API key into any chat window. Keys belong in a config file that you edit yourself. Anything pasted into a chat should be treated as exposed — that’s how keys end up being rotated at 2 a.m.
