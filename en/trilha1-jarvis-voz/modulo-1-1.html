BUILD YOUR OWN JARVIS

6 PROMPTS · ONE NIGHT · ONE TALKING AI SECOND BRAIN

This is the exact method I used to build JARVIS with the coding assistant—boiled down to a sequence of prompts anyone can run. Paste them in order, one at a time, and the assistant builds everything for you. No coding required. You just supervise.

What you'll have at the end: a 3D knowledge galaxy of your own notes · a voice assistant that answers out loud based on them · a camera that dives into the source · and a personality with a sharp wit that calls you "sir."

Before you begin (5 minutes)

The coding assistant installed and logged in → claude.com/claude-code

Google Chrome — the microphone and voice require it (Safari won't work)

A folder of markdown notes (Obsidian vault, Notion export, anything with .md files). Don’t have one? Prompt 1 covers that.

An API key for the assistant’s brain → console.anthropic.com ($5 in credits is enough; responses cost fractions of a cent)

⚠️ The only rule: never paste your API key into any chat window. You’ll type it yourself into a configuration file in Prompt 2. Anything pasted into a chat should be treated as exposed. Trust me on this.

Open a terminal, create an empty folder, and start the coding assistant inside it:

mkdir my-jarvis && cd my-jarvis && claude

Run the prompts in order. Let each one finish and test it before moving on to the next.
