Six ready-to-copy-and-paste prompts · No experience needed · 100% free

A robot that talks and actually does the work. You’re about to build CASE — a desktop robot that answers out loud and handles real tasks in the background: research, drafts, inquiries. It reports back when it’s done. Everything is built with your coding assistant, in a single file, and you paste the prompts below one at a time. If you can copy and paste, you can build this.

BEFORE YOU START · ABOUT 2 MINUTES

→ Install your coding assistant from claude.com/claude-code and open it in a new, empty folder.

→ Get an API key at console.anthropic.com and run export ANTHROPIC_API_KEY=your-key in your terminal.

→ Paste the six prompts in order. Let each one finish and test it before moving on to the next.

HOW IT WORKS

Each block on the following pages is a prompt. Copy the entire block, paste it into your coding assistant, and press enter. It writes the code for you and tells you how to run it. With the last prompt, you'll have a real, working robot that you can record on video and demonstrate.
