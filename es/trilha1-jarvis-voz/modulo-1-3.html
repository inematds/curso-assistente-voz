Now give my galaxy a brain — I want to type a question and get an answer from MY notes.

— Crea config.json en la raíz del proyecto (NO dentro de viewer/ — nunca debe ser accesible desde el navegador) con placeholders: {"api_key": "PUT-YOUR-KEY-HERE", "model": "TU-MODELO"}. Yo mismo pegaré mi clave de API en ese archivo — no me la pidas. — Agrega un endpoint POST /chat en server.py: califica cada nota según la superposición de palabras clave con mi pregunta (las coincidencias en el título tienen más peso), toma las 6 mejores y llama a la API de mensajes del modelo configurado en config.json con un prompt de sistema que diga: responde SOLO con base en estas notas, en 2–3 oraciones, y reconoce cuando las notas no cubran el tema. — El endpoint devuelve {"answer": "...", "nodes": [índices de las notas utilizadas]}. — Mantén un historial de conversación breve por sesión en el servidor para que funcionen las preguntas de seguimiento. — Agrega una barra de entrada elegante en la parte inferior del visualizador que muestre la respuesta en pantalla. — La clave de API nunca debe aparecer en el navegador, en el HTML ni en ningún archivo que sirva el servidor. — Cuando termines, reinicia el servidor y dame 3 preguntas de ejemplo para probar con base en mis notas reales.

Después: pega tu clave de API en config.json, recarga Chrome por completo e interroga a tu propio cerebro. ¿No tienes clave de API? Dile al asistente: "en vez de una clave de API, haz que /chat use el modo headless (claude -p) con mi suscripción." Es más lento, pero gratis.
